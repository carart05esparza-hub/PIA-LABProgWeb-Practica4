# PIA LABORATORIO DE PROGRAMACION WEB (Se utilizo la practica 4)

## Propósito
Muestra un pequeño inventario de una cafeteria, el stock de los productos se cambia en el archivo de inventario.json, si el stock de un producto es menor a 5, aparecera resaltado en rojo
